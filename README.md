# بصمة — تطبيق حضور وانصراف (Android)

كل موظف يبصم من موبايله ببصمة الإصبع، والتطبيق يتأكد إنه داخل موقع العمل بالـ GPS. الوقت يُسجَّل من السيرفر وليس من ساعة الموبايل.

## 1) تجهيز Firebase (مرة وحدة)
1. ادخل https://console.firebase.google.com وسوّي مشروع جديد.
2. **Authentication → Sign-in method**: فعّل **Anonymous** و **Email/Password**.
3. **Firestore Database → Create database** (Production mode).
4. **Firestore → Rules**: امسح الموجود والصق محتوى ملف `firestore.rules` ثم **Publish**.
5. **Project settings → Your apps → Web (</>)**: سجّل تطبيق ويب وانسخ قيم `firebaseConfig`.

## 2) بناء الـ APK عبر GitHub
1. سوّي مستودع جديد **Private** على GitHub.
2. ارفع كل محتويات هذا المجلد (ومن ضمنها مجلد `.github`).
3. افتح `app/src/main/assets/config.js` من GitHub واضغط ✏️ والصق قيم Firebase مكان كلمات `PASTE` ثم Commit.
4. تبويب **Actions** → آخر تشغيل لـ **Build APK** → بعد ما يخلص (≈5 دقائق) نزّل **basma-apk** من الأسفل وفك الضغط.
5. ثبّت `app-release.apk` على الموبايل (اسمح بالتثبيت من مصادر غير معروفة).

## 3) أول تشغيل
- **المدير:** «دخول المدير» → اكتب بريد وكلمة مرور → «إنشاء حساب المدير (أول مرة فقط)».
  - **الإعدادات:** روح لمكان العمل واضغط «تحديد موقع العمل من موقعي الحالي»، حدد النطاق (مثلاً 100 م) وأوقات الدوام وفترة السماح → حفظ.
  - **الموظفين:** أضف كل موظف → يطلع له رمز من 6 خانات → «مشاركة الرمز» (واتساب).
- **الموظف:** يثبت نفس الـ APK → «أنا موظف» → يدخل الرمز → يُربط بموبايله.
  - كل يوم: «بصمة حضور» عند الوصول، و«بصمة انصراف» عند الخروج.

## ملاحظات
- يجب أن يكون للموظف بصمة مسجلة بإعدادات موبايله.
- الرمز ينربط بموبايل واحد. إذا غيّر الموبايل أو حذف التطبيق: المدير يضغط «فك الربط».
- التطبيق يرفض: الموقع الوهمي (Fake GPS)، البصمة خارج النطاق، تكرار الحضور أو الانصراف بنفس اليوم.
- التقارير: من/إلى + موظف → ملخص (أيام، ساعات، تأخير) وتصدير CSV يفتح بـ Excel.
- التحديثات: أي تعديل تدفعه لـ GitHub يبني نسخة جديدة تتثبت فوق القديمة بدون فقدان الربط (التوقيع ثابت بملف `app/basma.jks`، لهذا خلّ المستودع Private).
- لتعديل الواجهة: عدّل `web/src/main.js` ثم داخل مجلد `web`:
  `npm install && npx esbuild src/main.js --bundle --minify --format=iife --target=chrome90 --outfile=../app/src/main/assets/app.js`
